# Public repository governance

## Ownership

The `Nexarion-Technologies` GitHub organization represents Nexarion Technologies, LLC. The organization owns its repositories and published project assets. Human administration is performed through individually attributable GitHub accounts; shared human logins are not used.

Nexarion is currently owner-led. [Rien Regalado](https://github.com/rienregalado) is the principal public maintainer and final approver for organization-level policy, repository ownership, releases, security posture, and publication scope.

## Contribution and decision model

Public repositories use a lightweight, evidence-oriented process:

1. define the problem, boundary, and non-goals;
2. discuss material behavior changes in an issue or pull request;
3. use synthetic or explicitly approved public data;
4. add tests, validation, and evidence appropriate to the change;
5. pass required automated checks;
6. complete security, privacy, licensing, and publication review;
7. merge through an approved repository workflow.

Maintainers may reject technically functional changes that expand authority, weaken boundaries, expose private implementation detail, or conflict with the repository's public purpose.

## Future collaborators

Future members and teams will receive only the repository and role access needed for their work. Organization membership does not imply access to private repositories, client systems, internal GitLab, unpublished Keystone material, credentials, commercial records, or production infrastructure.

Additional owners will be appointed only for a genuine continuity role with the authority and trust appropriate to full organization administration.

## Public and private authority

Public GitHub repositories are sanitized publication artifacts. Private GitLab repositories and governed internal systems remain authoritative for production implementation, private research, client adaptations, infrastructure, and proprietary operating material.

See `PUBLICATION_POLICY.md`, `SECURITY.md`, and `INTELLECTUAL_PROPERTY_NOTICE.md` for the controlling public boundaries.
