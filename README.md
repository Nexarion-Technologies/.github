# Nexarion Technologies organization profile

This repository publishes the public GitHub organization profile and default community health files for [Nexarion Technologies, LLC](https://www.nexariontechnologies.com/).

- `profile/README.md` renders on the organization Overview page.
- `SECURITY.md` defines private vulnerability-reporting expectations.
- `CONTRIBUTING.md` defines contribution boundaries for sanitized public demonstrations.
- `SUPPORT.md` separates public repository support from private or commercial support.
- `CODE_OF_CONDUCT.md` defines basic community conduct.
- `GOVERNANCE.md` defines public ownership, decision, and collaborator boundaries.
- `PUBLICATION_POLICY.md` defines the public/private publication boundary.
- `INTELLECTUAL_PROPERTY_NOTICE.md` clarifies the scope of repository licenses and retained proprietary material.
- `.github/ISSUE_TEMPLATE/` and `PULL_REQUEST_TEMPLATE.md` provide privacy-aware default contribution intake.

Public engineering repositories use synthetic data and sanitized architecture. Private GitLab repositories, client environments, internal topology, credentials, and unpublished Keystone specifications are not mirrored here.
